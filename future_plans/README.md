# Сховані та відкладені компоненти (Drafts / Stashed Components)

У цій папці зберігаються тимчасово вимкнені або нереалізовані елементи сайту, які заплановані до повернення після оновлення відповідних матеріалів.

## Список елементів

- [`open-cv-button.html`](./open-cv-button.html) — Кнопка **Open CV** з Header (десктопна та мобільна версії) та інструкція щодо її повторного ввімкнення після того, як нове CV буде готове.
